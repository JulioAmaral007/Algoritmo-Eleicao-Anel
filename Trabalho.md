## 1. INTRODUÇÃO

O trabalho engloba a elaboração de uma implementação que utilize os conceitos abordados em sala de aula, tais como sincronização, exclusão mútua, cliente-servidor, acordo, eleição de líder, entre outros. A escolha da linguagem de programação a ser utilizada fica a cargo do aluno.

O objetivo desta tarefa prática é permitir ao estudante a aplicação dos conceitos estudados na disciplina e empregá-los em uma implementação concreta.

## 2. ENTREGA

Os trabalhos devem ser submetidos até o dia **2 e 4 de julho** no ambiente Moodle, contendo os códigos dos arquivos acompanhados de um relatório que descreva o código e forneça instruções sobre como executá-lo.

## 3. Trabalho/Relatório

- Cada estudante deverá desenvolver um serviço de acordo com o protocolo e a linguagem escolhidos.
- O relatório no GitHub deverá conter, pelo menos, os seguintes elementos:
    - Uma descrição concisa da proposta do trabalho.
    - Detalhes sobre os requisitos funcionais do cliente e do servidor, como o tipo de requisição a ser enviada e recebida, a identificação dos processos, entre outros.
    - Uma explicação sobre a comunicação entre o cliente e o servidor. Se necessário, utilize um diagrama de sequência para descrever os passos dessa comunicação.
    - Uma descrição do serviço e como ele é executado no servidor.
    - No relatório e no código, inclua blocos de código que demonstrem a recepção e o envio de mensagens, a definição dos números dos processos e a forma de comunicação.
- Gerar o relatório a partir do Github

## 4. AVALIAÇÃO

- Será avaliada a execução da implementação proposta por cada grupo.
    - Comunicação entre um cliente que acessa o servidor de acordo com a aplicação proposta pelos grupos.
    - Avaliação do funcionamento da aplicação conforme a especificação proposta.
- Avaliação do relatório:
    - Descrição dos procedimentos de instalação, bibliotecas, configuração e execução da implementação para cada serviço, etc.
    - Descrição do serviço/método para a execução do algoritmo.
